# 🎀 Júlia Rosado | Portfólio

Portfólio pessoal em uma única página, com visual delicado, limpo e profissional. Este README descreve o que existe no código e como a interface está organizada.

## ✦ Sobre o projeto

O site foi criado para apresentar minha trajetória como desenvolvedora fullstack em formação, reunindo uma introdução curta, projetos acadêmicos e profissionais, formação, linguagens, ferramentas e contato.

O foco foi manter uma identidade feminina sutil, com tons de rosa bem claros, bastante espaço em branco, tipografia elegante e navegação suave.

## ✦ Seções da interface

- Hero com nome, resumo profissional e botões de destaque
- Sobre mim com apresentação curta e direta
- Projetos com descrição, tecnologias e links dos repositórios
- Formação acadêmica e idiomas
- Linguagens e ferramentas usadas no dia a dia
- Contato com GitHub, LinkedIn, email e portfólio atual

## ✦ Tecnologias

- HTML5
- CSS3
- JavaScript
- Fonte via Google Fonts

## ✦ Estrutura de pastas

```text
docs/
  index.html
  assets/
    css/
      styles.css
    js/
      script.js
    img/
      foto-julia.png
```

## ✦ O que existe no código

- Uma estrutura HTML única em `docs/index.html`
- Estilo visual concentrado em `docs/assets/css/styles.css`
- Comportamentos leves de interface em `docs/assets/js/script.js`
- Pasta `docs/assets/img/` reservada para foto e futuras imagens

## ✦ Visual

- Paleta baseada em rosa claro, com fundo quase branco
- Texto em rosa escuro para manter contraste suave
- Cartões com bordas arredondadas e sombras leves
- Spacing amplo para leitura confortável
- Animações discretas para entrada das seções
